# Simple Commander v1.0.6

토탈커맨더 스타일의 듀얼 패널 파일 매니저

## 기능

- 🔄 듀얼 패널 파일 탐색
- 📋 파일 복사/이동/삭제
- 🔍 파일 검색
- 📦 ZIP 압축/해제
- ✨ 다중 파일 선택 (Ctrl, Shift)
- ⌨️ 단축키 지원 (F3-F8)
- 🎨 깔끔한 UI

## 설치 및 실행

### 요구사항
- Python 3.6 이상
- tkinter (Python 기본 포함)

### 실행 방법
```bash
python Simple_commander.py
```

## 사용법

### 단축키
- **F3**: 파일 보기
- **F4**: 파일 편집
- **F5**: 복사
- **F6**: 이동
- **F7**: 새 폴더
- **F8**: 삭제
- **Ctrl+A**: 전체 선택
- **Ctrl+C**: 복사
- **Ctrl+V**: 붙여넣기
- **Delete**: 삭제

### 다중 선택
- **Ctrl + 클릭**: 개별 선택/해제
- **Shift + 클릭**: 범위 선택
- **스페이스바**: 토글 선택
